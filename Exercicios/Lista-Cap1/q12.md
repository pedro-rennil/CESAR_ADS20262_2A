### Tabela de Análise de Declaração de Variáveis

| Instrução | Status (C/I) | Justificativa Teórica |
| :--- | :--- | :--- |
| a) `int a;` | **Correto** | Declaração válida de variável inteira padrão. |
| b) `float b;` | **Correto** | Declaração válida de ponto flutuante de precisão simples. |
| c) `double float c;` | **Incorreto** | Tipo inválido. `double` e `float` são tipos primitivos mutuamente excludentes. Para estender a precisão de um flutuante usa-se `long double`. |
| d) `unsigned char d;` | **Correto** | Declaração válida de caractere de 1 byte sem sinal, com faixa expandida de 0 a 255. |
| e) `unsigned e;` | **Correto** | Se o tipo básico for omitido após o modificador `unsigned`, a linguagem C assume por padrão o tipo `int` (equivalente a `unsigned int`). |
| f) `long float f;` | **Incorreto** | Incompatível com o padrão ANSI C moderno. O termo `long float` foi removido e substituído inteiramente por `double`. |
| g) `long g;` | **Correto** | Se o tipo for omitido após `long`, assume-se `long int` (inteiro longo). |
| h) `long double h;`| **Correto** | Declaração válida de flutuante de precisão estendida (normalmente 10 ou 16 bytes). |
