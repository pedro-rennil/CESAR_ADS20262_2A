### Versão 1: Um único `printf()` (`questao21_v1.c`)
```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    printf("Treinamento em programação.\nLinguagem C.\n");
    system("PAUSE");
    return 0;
}
```
