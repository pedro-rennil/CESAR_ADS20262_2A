**a) `i < j + 3`**
*   **Precedência:** O operador de adição (`+`) tem precedência sobre o relacional (`<`).
*   **Passos:** `1 < (2 + 3)` $\rightarrow$ `1 < 5`
*   **Resultado:** **1** (Verdadeiro)

**b) `2 * i - 7 <= j - 8`**
*   **Precedência:** Multiplicação (`*`), depois subtração (`-`), depois relacional (`<=`).
*   **Passos:** `(2 * 1) - 7 <= (2 - 8)` $\rightarrow$ `2 - 7 <= -6` $\rightarrow$ `-5 <= -6`
*   **Resultado:** **0** (Falso)

**c) `-x + y >= 2.0 * y`**
*   **Precedência:** Menos unário (`-`), multiplicação (`*`), adição (`+`), relacional (`>=`).
*   **Passos:** `(-3.3) + 4.4 >= (2.0 * 4.4)` $\rightarrow$ `1.1 >= 8.8`
*   **Resultado:** **0** (Falso)

**d) `x == y`**
*   **Passos:** `3.3 == 4.4`
*   **Resultado:** **0** (Falso)

**e) `!(n - j)`**
*   **Precedência:** Parênteses resolvem primeiro, depois a negação lógica (`!`).
*   **Passos:** `!(2 - 2)` $\rightarrow$ `!(0)`
*   O inverso de Falso (0) é Verdadeiro (1).
*   **Resultado:** **1** (Verdadeiro)

**f) `!n - j`**
*   **Precedência:** A negação lógica (`!`) tem precedência sobre a subtração (`-`).
*   **Passos:** `(!2) - 2`. Como 2 é diferente de zero (verdadeiro), `!2` resulta em `0`. Então fica `0 - 2`.
*   *Nota:* Embora a questão peça 1 ou 0, essa expressão avalia matematicamente para um número negativo, o que é uma típica "pegadinha" de precedência.
*   **Resultado:** **-2** (Se for estritamente cobrado um valor booleano em um teste de mesa que converte a saída, seria considerado verdadeiro por ser diferente de zero, mas o valor da expressão em C é `-2`).

**g) `i && j && k`**
*   **Passos:** `1 && 2 && 3`. Todos os valores são diferentes de zero (Verdadeiros). Verdadeiro E Verdadeiro E Verdadeiro.
*   **Resultado:** **1** (Verdadeiro)

**h) `i || j - 3 && k`**
*   **Precedência e Curto-circuito:** O operador `||` (OU) avalia da esquerda para a direita. Como `i` é `1` (Verdadeiro), a linguagem C aplica o **curto-circuito** e não precisa avaliar o resto da expressão (pois `Verdadeiro OU qualquer_coisa` é sempre Verdadeiro).
*   **Resultado:** **1** (Verdadeiro)

**i) `i < j && 2 >= k`**
*   **Precedência:** Relacionais (`<`, `>=`) resolvem antes do lógico `&&`.
*   **Passos:** `(1 < 2) && (2 >= 3)` $\rightarrow$ `1 && 0` $\rightarrow$ Verdadeiro E Falso.
*   **Resultado:** **0** (Falso)

**j) `i == 2 || j == 4 || k == 5`**
*   **Passos:** `(1 == 2) || (2 == 4) || (3 == 5)` $\rightarrow$ `0 || 0 || 0` $\rightarrow$ Falso OU Falso OU Falso.
*   **Resultado:** **0** (Falso)
